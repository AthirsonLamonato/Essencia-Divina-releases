# Essência Divina — downloads

Jogo de cartas de blefe online entre deuses gregos, em primeira pessoa, de 2 a 8 jogadores.

Este repositório só guarda os executáveis prontos. O código-fonte é privado.

## Como jogar

1. Abra a [última versão](https://github.com/AthirsonLamonato/Essencia-Divina-releases/releases/latest).
2. Baixe `EssenciaDivina-windows.zip` e descompacte numa pasta.
3. Abra `EssenciaDivina.exe`.

O jogo avisa sozinho quando sai versão nova e se atualiza com um clique.

O servidor é gratuito e dorme quando ninguém joga: a primeira conexão pode levar até um minuto.
